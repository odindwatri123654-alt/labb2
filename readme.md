# Проверка сложности и генерация паролей

Учебная лабораторная работа на Python. В меню два действия:

1. Проверить свой пароль: получить оценку сложности и советы.
2. Сгенерировать сложный пароль.

Пункт `0` завершает работу.

## Запуск

Нужен Python 3.10 или новее. Дополнительных библиотек нет.
Распакуйте архив и откройте терминал в папке `password_simple`:

```bash
python main.py
```

В Windows также можно использовать `py -3 main.py`.

## Генерация

Введите длину от 16 до 128 символов. В каждом результате обязательно есть:

- хотя бы одна заглавная латинская буква;
- хотя бы одна цифра;
- хотя бы один спецсимвол из `!@#$%^&*()-_=+?`.

Программа сначала выбирает обязательные символы, добавляет случайные символы
до нужной длины и перемешивает их. Используется стандартный модуль `secrets`.
Если вариант содержит простой шаблон или три одинаковых символа подряд,
генерация повторяется. Готовый пароль выводится на экран.

## Проверка своего пароля

- Надёжный: от 16 символов, есть заглавная латинская буква, цифра и ASCII-спецсимвол,
  нет известных программе простых шаблонов и трёх одинаковых символов подряд.
- Средний: не выполнены все условия надёжного, но есть минимум 12 символов
  и две группы символов, нет простых шаблонов и тройных повторов.
- Слабый: остальные непустые варианты.

Четыре учитываемые группы: `a-z`, `A-Z`, `0-9`, ASCII-знаки пунктуации.
Кириллица и пробелы учитываются в длине, но не добавляют группу.
Пустой пароль и строка только из пробелов вызывают ошибку.
Пробелы по краям не удаляются.

Простые шаблоны: `password`, `qwerty`, `123456`, `abcdef`, `admin`, `letmein`,
`пароль`. Они ищутся в любой части строки без учёта регистра.
Оценка учебная: это не проверка утечек и не гарантия безопасности.

## Пример

1. Выберите `1`, введите `123456`: оценка «слабый» и советы.
2. Выберите `1`, введите `mR7!vT2#kL9?xB4$`: оценка «надёжный».
3. Выберите `2`, введите длину `20`: получите случайный пароль.
4. Введите `0` для выхода.

Ввод видимый. Примеры предназначены для демонстрации.

## Файлы и слои

| Файл | Назначение |
|---|---|
| `main.py` | Точка входа: меню, ввод и вывод |
| `models.py` | dataLayer: класс результата PasswordResult |
| `repository.py` | repositoryLayer: CRUD результатов в словаре |
| `service.py` | serviceLayer: правила проверки и генерации |

Меню вызывает сервис, сервис сохраняет результат через репозиторий.
Результат содержит номер, длину, число групп, оценку и советы, без текста пароля.
Результаты живут в памяти до закрытия программы. Отдельного меню истории нет.
Полный CRUD репозитория оставлен для структуры задания; текущие сценарии
используют добавление результата.

У каждой части своя ответственность (SRP). Репозиторий передаётся конструктору
сервиса: другое хранилище с теми же методами можно подключить без изменения
правил проверки. Сервис напрямую к словарю не обращается.

## GitHub: три коммита для нового репозитория

Создайте пустой репозиторий `password-lab`, без README и .gitignore.
Откройте PowerShell в папке `password_simple`. Подставьте свои имя, почту и логин:

```bash
git init
git config user.name "Ваше имя"
git config user.email "Ваша почта"
git branch -M main
git add models.py repository.py .gitignore
git commit -m "Добавлены модель и репозиторий"
git add service.py
git commit -m "Добавлены проверка и генерация паролей"
git add main.py readme.md
git commit -m "Добавлены меню и инструкция"
git remote add origin https://github.com/YOUR_USERNAME/password-lab.git
git push -u origin main
```

Если предыдущая версия уже отправлена в этот репозиторий, замените файлы проекта
новыми и выполните только:

```bash
git add main.py service.py readme.md
git commit -m "Оставлены проверка и генерация паролей"
git push
```
